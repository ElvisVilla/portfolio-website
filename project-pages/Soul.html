Soul

Overview

Building a world through code and colors.

Soul is a 2D platform prototype developed in Unity to experiment with the Engine, with a focus on atmospheric environment, and platforming systems.

  • Implemented player mechanics using FSM, Input handling and Animation transitions
  • Built atmosphere through lighting, post-processing effects, particle systems
  • Tiled2D for map creation
  • Implemented Dialogue Systems using Yarn Spinner package
  • Character design and Enemy design using pixel art
