Overview

Building a modular gaming experience.

Cutebit is a responsive casino application developed in Godot in collaboration with the design and backend teams. I designed and implemented the client-side architecture, integrating multiple minigames, game modes, and real-time backend communication.

  • Designed and implemented the client application architecture of a modular and responsive casino application.
  • Implemented two well known minigames for the project ensuring that the application can load multiple game types.
  • Implemented basic mode, automatic mode, advanced mode and user defined rules that work for each individual minigame.
  • Backend communication for CRUD operations through HTTP requests and Websockets for real-time game sessions.
  • Implemented session statistics and win/loss visualizations.
  • Created UI animations and transitions using Godot Tweens.
