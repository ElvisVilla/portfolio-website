Overview

Building a world through code and colors.

Cutebit is a casino application developed in collaboration with the design team and backend team.

  • Design and implemented the client aplication architecture, of amodular and responsive casino application
  • Implementation of 2 well known minigames for the project ensuring that the application can load multiple types of minigames
  • Implemented Basic Mode, Automatic mode + user defined rules, and finally Advance Modes, that works for each individual minigame
  • Backend communication for CRUD operations through HTTP request and Websocket for realtime server comunication with mini games session.
  • Stats visualization for win and loose on playing sessions
  • Animation implementation of UI events using godot tweens
