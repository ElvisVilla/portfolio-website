Building a world through code and colors.

Declarative framework inspired in SwiftUI for UI declaration

  • Implemented code generators to overcome GDScript Syntax limitations for UI Clases
  • Observable types implementation to enable a reactive approach by leveraging Godot Signals
  • Observable types can also animate its values, enabling seamless animation when the value changes
  • Implemented new default sizing approach for more a dynamic sizing, childs requrest parent to grow recursively
  • Implemented Builder pattern for the UI creation based on the declarative definition in source
