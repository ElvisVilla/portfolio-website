Overview

Building a world through code and colors.

Transpiled Programming Language implemented in GDScript following the book "Crafting Interpreters" from Robert Nystrom. This project is an exploration of how programming languages work, GDBraces completes the implementation of Tree Walk Interpreter + my own effort of implementing the Transpiler have GDBraces source code work directly to Godot

  • Tokenizer: from the book and a few more tokens implemented by myself
  • Parser: Ensures syntax correctness and reports errors messages. Its output is a Tree Tokens that represents the semantics of the program
  • Resolver: analyzes the scope of variables on each block of code to ensure variables exist before execution
  • Interpreter: Executes the instructions of the program
  • Transpiler: Code generation to take GDBraces syntax into GDScript syntax that can be executed at runtime, this enables GDBraces as an scripting language for Godot Engine. Its implementation is still partial and more of an exploration than as a final usable solution
  • Implemented Godot plugins: ResourceLoader, ResourcerSaver, ContextMenuPlugin and EditorInspectorPlugins for a more robust integration in the Engine
