Overview

Godot Wild 85: Game Jam Collaboration.

MyColony was created during an 8-day game jam in collaboration with one other developer. The Gameplay focuses on resource management and growth mechanics. The goal of the game is to gather resources and avoid them from running out to make the mushroom grow. If resources run out, the game is over.

  • Co-designed the game's mechanics and visual direction; created tile set, props and pixel-art assets.
  • Designed and created the environment art and enemies.
  • Developed mycelium tileable art
  • Designed the game's itch.io capsule artwork and presentation.
