Overview

Improving UI development workflows in Godot.

By creating VisualUI, I developed a tool I would have loved to have in some of my previous projects. This plugin implements a context toolbar for easier UI styling and sizing in Godot engine. Commercial release planned.

  • Designed and developed the entire product proposition: A responsive toolbar that encapsulates and simplifies UI for users by improving sizing semantics for UI layout, replacing the Godot UI fill approach with the FitContent approach.
  • The user is meant to easily be able to style the UI by using a modifiy tab to faster lookup which properties where modified in an object, giving a better experience of UI creation in Godot.
  • Implemented the UI design, layout, and interactions of the plugin.
  • Evolves and re-implements work first done in GDScriptUI, a declarative UI framework inspired by SwiftUI for Godot engine, into an integrated plugin editor.
