Overview

Building a world through code and colors.

Cutebit is a casino application developed in collaboration with the design team and backend team.

  • Design and developed the product proposition: Simplifying Sizing semantics for UI Layout, replacing Godot UI fill approach to FitContent Approach.
  • ToolBar that encapsulates and simplify how the user styles the UI, modified tab to faster lookup of what properties where modified in an Object.
  • Reimplements the work done in GDScriptUI into an integrated plugin editor, giving a better experience of the UI creation in Godot.
