Overview

Building a world through code and colors.

Gerne is a learning companion for students in a language class. Gerne embeds a Dictionary for word lookup, all the words you search gets save in your wordlist, the list purpose is to let you know what are the most searched words you have done, the app also includes flash cards that you can use for practicing the words in your wordlist. The app also embeds a translator that supports 21 languages powered by TranslationKit from Apple frameworks.

  • Design and developed the entire product proposition for a Language Learning app that focused on improving language learning experience for students learning a language in class
  • Implemented UI Design, Layout, Interactions and animation of the entire application
  • Implemented a Flash Card Game. WordList with Query, Filters and Sorting functionality
  • Local Storage with SQLite + Supabase as cloud storage and user Authentication, API request to Wiktionary for Dictionary Lookup. Multiple Apple Frameworks like TranslationKit.
